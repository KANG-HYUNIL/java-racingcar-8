# java-racingcar-precourse

1. 입력을 받는 모듈
2. 입력을 쉼표(,) 기준으로 쪼개서 자동차 이름을 얻어내는 모듈
3. 자동차 이름이 모두 5자 이하인지 검증하는 모듈
4. 시도할 횟수를 담아둘 모듈
5. 0에서 9 사이의 무작위 값을 만들어내고, 무작위 값이 4 이상인지 여부를 알려주는 모듈
6. 자동차 경주 게임을 진행하면서, 각 자동차별로 전진 횟수를 관리할 모듈
7. 우승자 목록을 도출해낼 모듈
8. 차수 별로 실행 결과를 출력해줄 모듈
9. 최종 우승자 목록을 출력해줄 모듈

우선 이렇게 기능을 쪼갤 수 있을 것 같고(우선 아주 작은 단위로), 이를 이제 실제 클래스로 묶어서 기능 모듈을 넣어둔 형태로 만들어보자. 실제 개발은 클래스 단위로 해보자고.

1. **Car Class**

자동차의 이름과 현재 전진 횟수를 관리. 

포함하는 기능은:

- 자동차 이름 저장(생성자로) - 2번 기능 연관
- 현재 자신의 위치 저장 - 6번 기능 연관
- 주어진 조건을 보고 전진하는 기능 - 5번 기능 연관
- 자신의 위치를 자신의 이름과 함께 (-)로 출력하는 기능 - 8번 기능 연관

1. **GameController Class**

자동차 게임의 흐름을 제어.

포함하는 기능은:

- Car 객체들을 관리
- 시도할 횟수 만큼 경주를 진행시키는 기능 - 4번, 6번 기능 연관
- 최종 우승자 목록을 결정하는 기능 - 7번 기능 연관

1. **InputHandler Class**

실제 입력을 받아주기.

포함하는 기능은:

- 자동차 이름 입력 받기 - 1번 기능 연관
- 시도할 횟수 받기 - 1번 기능 연관

1. **OutputHandler Class**

출력 양식에 맞게 출력해주기.

포함하는 기능은:

- 차수 별 실행 결과 출력 - 8번 기능 연관
- 최종 우승자 출력 - 9번 기능 연관

1. **Validator**

입력값의 유효성 검증

포함하는 기능은:

- 자동차 이름 5자 이하 검증 - 3번 기능 연관
- 시도 횟수의 양수 검증
